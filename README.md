## 🎯 Sobre o Repositório

Este repositório serve como um **diário de bordo técnico** e portfólio de lógica. Aqui estão organizadas as minhas soluções para os desafios (katas) do [Codewars](https://www.codewars.com), abordando desde os níveis iniciantes até os mais complexos. 

O principal objetivo é praticar a resolução de problemas de forma limpa (*clean code*), testar diferentes abordagens para o mesmo algoritmo e consolidar a base técnica de desenvolvimento.

---

## 📁 Estrutura de Organização

Os desafios são categorizados para facilitar a navegação e visualização do progresso:

```text
.
├── 8kyu/          # Iniciante / Conceitos básicos
├── 7kyu/          # Intermediário básico
├── 6kyu/          # Intermediário avançado (Foco em otimização)
└── 4kyu/          # Avançado / Algoritmos complexos
```
